# خرج‌یار

یک وب‌اپ فارسی و راست‌به‌چپ برای ثبت هزینه، بودجه‌بندی و هدف‌های پس‌انداز. اطلاعات در مرورگر کاربر ذخیره می‌شود؛ هیچ داده‌ای به سرور ارسال نمی‌شود.

## اجرا

برای استفاده سریع، `index.html` را با مرورگر باز کنید. برای نصب به‌عنوان اپ و فعال شدن حالت آفلاین، پوشه را روی هر میزبان استاتیک (GitHub Pages، Netlify، Vercel یا Nginx) منتشر کنید.

## امکانات

- ثبت، ویرایش و حذف هزینه با تاریخ شمسی
- دسته‌بندی خودکار بر اساس کلیدواژه
- مدیریت بودجه و هدف‌های پس‌انداز
- گزارش دسته‌بندی و روند شش‌ماهه
- فیلتر هزینه‌ها و خروجی CSV
- ذخیره‌سازی محلی و پشتیبانی از نصب PWA

## بهبودهای نسخه ۶

- جست‌وجوی فوری در عنوان، یادداشت و افراد؛ به‌همراه فیلتر شخص، حداقل مبلغ و مرتب‌سازی
- ثبت هزینه‌های ماهانهٔ تکرارشونده و تولید خودکار رخدادهای ماه‌های بعد
- هشدار هنگام نزدیک شدن به سقف بودجه یا عبور از آن
- مقایسه با ماه قبل، بزرگ‌ترین هزینه و مرور ماهانهٔ قابل‌فهم
- سطل بازیافت برای برگرداندن حذف‌های اشتباهی
- خروجی پشتیبان کامل JSON و بازیابی کنترل‌شده، در کنار CSV برای اکسل
- میانبر `/` برای رفتن به جست‌وجو و `N` برای ثبت سریع هزینه (وقتی در یک فیلد نوشتاری نیستید)

## طراحی رابط کاربری

نسخهٔ فعلی با زبان طراحی «Financial Calm» ساخته شده است: پس‌زمینهٔ عمیق زمردی، طلایی گرم برای نقاط تصمیم، کارت‌های شیشه‌ای کم‌کنتراست، سلسله‌مراتب واضح اطلاعات و حرکت‌های کوتاه و هدفمند. در دسکتاپ ناوبری به یک ریل فشرده تبدیل می‌شود و در موبایل، به ناوبری پایین صفحه؛ بنابراین تجربه روی هر اندازه صفحه طبیعی باقی می‌ماند. تنظیمات کاهش حرکت سیستم نیز رعایت می‌شود.

برای دسترسی سریع، کلید `/` منوی دستورها را باز می‌کند، `N` فرم ثبت هزینه را باز می‌کند و `?` میانبرها را نمایش می‌دهد. از تنظیمات می‌توانید اندازهٔ متن و کنتراست را به‌صورت ماندگار تغییر دهید.

## نکتهٔ حریم خصوصی

پاک کردن داده‌های سایت در مرورگر، اطلاعات محلی خرج‌یار را هم پاک می‌کند. پیش از آن از خروجی CSV نسخهٔ پشتیبان بگیرید.
